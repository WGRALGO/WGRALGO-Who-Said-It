# Who Said It? — Knowledge Is the Weapon™ Edition · v1.0.0

First public Android release.

- Offline quote-recognition game with 80+ attribution-checked questions
- 10 randomized rounds per game across 14 wisdom categories
- Instant feedback, speaker reveal, and quote explanation
- Final rating screen with Play Again
- WGRALGO black-and-gold design language
- No internet permission, no analytics, no trackers, GPLv3 licensed

## Install

Download `WhoSaidIt-v1.0.0.apk` below and sideload it on Android.

Verify integrity (optional):

```bash
sha256sum WhoSaidIt-v1.0.0.apk
# should match WhoSaidIt-v1.0.0.apk.sha256
```
