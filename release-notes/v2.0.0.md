# Who Said It? v2.0.0

Works on phones and tablets, in portrait and landscape. Like earlier versions, it works offline, with no ads, analytics, trackers, or account.

## What's new
- **New quote bank:** 66 quotes across **Beginner**, **Everyday**, and **Expert**, plus an **All Levels** round.
- **Two kinds of questions:** 🗣️ *Who said it?* and 🔍 *Real or misattributed?* Learn to spot famous quotes that were never really said.
- **Every answer shows the real source** and the story behind the quote, plus tips on how to check a quote before you share it.
- **Looks like a real app:** black launch screen with the big logo, a bigger launcher icon, solid app bar, and About / Privacy / Credits panels.
- **Back button works:** asks before quitting a round, returns to the level picker from results, and asks before exiting.
- **Phones and tablets, portrait and landscape:** the app rotates freely, and the start screen fits landscape phones.
- The APK is now named `WGRALGO-WhoSaidIt-v2.0.0.apk`, like every WGRALGO app.
- Still **100% offline**: no internet permission.

## Important: uninstall v1.0.0 first

This release is signed with a new key, so it can't install over v1.0.0. Uninstall the old app first. The app saves nothing, so nothing is lost.
